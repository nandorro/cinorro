# Cinorro (web)

Cartelera de cines de Madrid y Ávila: https://nandorro.github.io/cinorro/

- `index.html`: la web.
- `cines.json`: lista de cines (ID de Sensacine, color, zonas).
- `descargar.py`: descarga las carteleras de los próximos 7 días.
- `.github/workflows/pages.yml`: lo ejecuta cada 4 horas y publica en GitHub Pages.
